# Landing de Alicia Viñolas

Landing en Next.js, TypeScript y Tailwind para `ALICIA VIÑOLAS · CURATED EVENTS`.

Todo el copy editable y las URLs de imágenes temporales están centralizados en `data/siteContent.ts`.

## Desarrollo

```bash
npm install
npm run dev
```

## Imágenes temporales

El prototipo usa imágenes públicas temporales para poder evaluar la dirección visual. Antes de publicar hay que sustituirlas por:

- Retrato real de Alicia.
- Fotografías reales de eventos corporativos.
- Detalles reales de bienvenida, mesa, preparación y producción.

No se han inventado clientes, testimonios, cifras ni casos de éxito.
